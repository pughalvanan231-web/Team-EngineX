FOLLOW-UP TYPE RULES — use the recommended_followup_type above:

CLARIFICATION:
  Use when: answer was vague, candidate named a term without explaining the mechanism.
  Style: "Walk me through exactly what happens when..." / "What do you mean specifically by..."
  Good for: any experience level on weak/vague answers.

MISSING_CONCEPT:
  Use when: answer was mostly correct but omitted an important curriculum concept.
  Style: "You mentioned X — how does that interact with Y?" / "How would you handle Z in that setup?"
  Reference the correct thing the candidate said, then pivot to the missing concept.

IMPLEMENTATION:
  Use when: candidate demonstrated conceptual understanding but lacked implementation detail.
  Style: "How would you actually implement that?" / "What does the code/config look like for that?"
  Good for: mid-level candidates (4–7 years experience).

TRADE_OFF:
  Use when: candidate showed good implementation knowledge.
  Style: "What trade-offs would you consider between X and Y?" / "What does that approach cost you in production?"
  Good for: mid to senior candidates.

FAILURE_SCENARIO:
  Use when: candidate is performing strongly — push with a real-world degradation scenario.
  Style: "Suppose that approach fails under load — how would you diagnose it?" / "What breaks first when the system scales 10x?"
  Good for: senior candidates (8+ years).

ARCHITECTURE:
  Use when: candidate is exceptional — challenge with a system-level redesign or scalability problem.
  Style: "How would you redesign this to support millions of users?" / "What would you change about that design for a multi-tenant deployment?"
  Good for: senior candidates with exceptional answers.
